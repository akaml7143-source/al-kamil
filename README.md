# الكامل

تطبيق إسلامي شامل مبني باستخدام Flutter وبواجهة عربية من اليمين إلى اليسار.

## البناء

يتولى GitHub Actions تثبيت Flutter وتشغيل التحليل وبناء APK عند كل دفع إلى الفرع الرئيسي، أو عند تشغيل workflow يدوياً من تبويب Actions.

## الأقسام المخطط لها

- القرآن الكريم
- مواقيت الصلاة للدول والمدن
- الأدعية والزيارات
- الصحيفة السجادية
- نهج البلاغة
- وصايا أهل البيت (عليهم السلام) مع توثيق المصادر وبيان درجات النسبة
- المناسبات الإسلامية
- القبلة والتسبيح

المشروع في مرحلة التأسيس. لا تُعرض نصوص أو مواقيت غير متحققة على أنها بيانات موثوقة.
