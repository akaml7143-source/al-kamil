# تطبيق الكامل

موسوعة إسلامية عربية تعمل دون الحاجة إلى إنشاء حساب، مع واجهة RTL وتصميم Twilight Glassmorphism.

## الوظائف الحالية

- القرآن الكريم: مصحف حفص مع التجويد الملوّن، فهرس السور، حفظ آخر صفحة، الورد اليومي والعلامات المرجعية.
- الصلاة والقبلة: مواقيت الصلاة حسب إعدادات المدينة وطريقة الحساب، واتجاه القبلة.
- المكتبة: الزيارات والأدعية وتعقيبات الصلوات ومناجاة الإمام السجاد (ع)، مع البحث والمفضلة وآخر قراءة.
- تعليم صلاة الليل والمسبحة الإلكترونية.
- التقويم الميلادي مع عرض التاريخ الهجري الحسابي التقريبي؛ وقد يختلف عن التقويم الرسمي بحسب ثبوت الهلال.
- التذكيرات الشخصية المحفوظة محلياً داخل التطبيق، والنسخ الاحتياطي والاستعادة عبر نص منسوخ.

## الخصوصية والعمل دون إنترنت

تُحفظ بيانات القراءة والمفضلة والورد والتذكيرات على الجهاز. النسخ الاحتياطي يُنشأ محلياً ويُنسخ إلى الحافظة ولا يُرسل إلى خادم. التذكيرات الحالية قائمة داخل التطبيق وليست إشعارات نظام تعمل بعد إغلاق التطبيق.

## البناء والتحقق

يشغّل GitHub Actions تنسيق Dart والتحليل والاختبارات ثم يبني APK إصداراً عند كل تحديث للفرع الرئيسي أو تشغيل يدوي لسير العمل.
